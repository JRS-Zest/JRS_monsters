ここでは図鑑の数値がどのように決まるかを説明します。 「floor」は小数点以下を切り捨てる意味です。 難しい調査内容は、各項目の「調査メモ（技術的な内容）」に折りたたんでいます。
ステータス（STR / AGI / CON / WIS / INT / CHA / LCK）
stat = floor( 基礎値 × ((Lv−1) × SF + 100000) / 100000 )
レベルが1上がるごとに、モンスターの種類ごとに決まった割合でステータスが上がります。
調査メモ（技術的な内容）
SF = job2.dat offset 0x34 (ushort) / BasicPowerLevelFactor。JRS job2 の 328 バイトレコードで確認。
「INT⇔WIS入替」とは？
モンスターの種類によっては、ゲーム内部のデータで 「知恵（WIS）」と「知識（INT）」が通常と逆に入っています。 ゲーム側の計算に合わせるため、この図鑑ではそのモンスターだけ WIS と INT を入れ替えて表示しています。 カードの数値は、この入れ替え後の値です。
例：シーフ（データ上 WIS6 / INT5）→ 表示 WIS5 / INT6（レベル10なら WIS9 / INT11）
例：The_End（データ上 WIS151 / INT37）→ 表示 WIS37 / INT151（レベル2550なら WIS6,287 / INT25,658）
魔法抵抗は WIS を使って計算するため、入れ替えの影響を受けます。
入れ替えるかどうかはモンスターごとに固定で、ランダムに変わることはありません。
調査メモ（技術的な内容）
job2.dat offset 0x2E bit6（IsReviseIntCalc）と RMD グループ flags1 bit5（IsReviseIntelligence）の OR が 0 のとき入れ替え。 参考サーバ CActor.cpp / cACTOR::setStatus() の分岐。
MaxHP
MaxHP = floor( (DefaultHP + CON×StateBonus×10 + Lv×LevelUpBonus×10) / 100 × correct_hp/100 )
HPはレベル・CON・種類ごとの成長値で決まり、マップごとの「HP補正」が掛かります。
調査メモ（技術的な内容）
DefaultHP = offset 0xFC / LevelUpBonus = 0x108 / StateBonus = 0x10A。correct_hp は RMD グループ補正。
MaxCP
MaxCP = floor( (DefaultCP + CHA×100 + Lv×100) / 100 )
CPはレベルとCHAで決まります。HPのようなレベルアップ成長値やマップ補正は使われません。
調査メモ（技術的な内容）
DefaultCP = offset 0x100。旧サイトの「LevelUpBonus/StateBonus を HP と共有」する式は誤りのため修正。
攻撃力
Min = ( AtkMin + (Lv−1) × AtkMinG/100 ) × ( 1 + STR/200 )
Max = ( AtkMax + (Lv−1) × AtkMaxG/100 ) × ( 1 + STR/200 )
攻撃力はレベル・STR・種類ごとの成長値で決まります。マップの「与ダメ補正」は攻撃力表示とは別に、実際のダメージへ掛かります。
調査メモ（技術的な内容）
AtkMin = 0x11C / AtkMax = 0x11E / AtkMinG = 0x36 / AtkMaxG = 0x38。旧データの Max/Min ラベルは逆だったため整理。
防御力
Def = ( DefenceValue + (Lv−1) × DefenceBonus/100 ) × ( 1 + CON/100 )
防御力はレベル・CON・種類ごとの成長値で決まります。
調査メモ（技術的な内容）
DefenceValue = 0x120 / DefenceBonus = 0x3A。
魔法抵抗（火/水/風/土/光/闇）
MagRes[i] = 基礎値[i] + floor( WIS × 5 / 100 )
WISが高いほど、全属性の魔法抵抗が上がります。モンスターは上限なしで計算しています。
調査メモ（技術的な内容）
WIS×5/100 = WIS/20。参考サーバの getFireResistance() 等。純モンスターは上限なし（旧サイトの WIS/30 は誤り）。
状態異常抵抗
AbnRes[i] = 固定値（レベル・ステータス依存なし）
状態異常への耐性は、モンスターごとに決まった固定値です。レベルでは変わりません。
調査メモ（技術的な内容）
全状態異常共通耐性・全呪文耐性・全衰退耐性も同様。
取得EXP
EXP = floor( DefaultEXP × (Lv+4) × 10 × correct_exp/100 / 100 )
倒したときに得られるEXPは、モンスターのレベルとマップ補正で変わります。
調査メモ（技術的な内容）
DefaultEXP = offset 0x54。correct_exp は RMD グループ補正（既定100%）。
マップ側の補正値（cCHARACTER / RMD 6.1）
correct_hp / correct_exp / correct_ap / correct_final_damage / scale_x / scale_y / max_level
同じモンスターでも、マップによってHP・EXP・与ダメが変わる場合があります。カードのバッジはその補正です。
調査メモ（技術的な内容）
MapActorGroup の 0x1A〜0x26。HP・EXP・与ダメ補正としてカードに表示（非100%のみバッジ）。
リポップ速度（再出現周期）
マップデータに「再出現までの秒数」が入っており、その値を表示しています。サーバ設定で短縮・延長される場合や、秘密の部屋などテスト用マップに特殊な値が入っている場合があります。
表示例: 🔄 10秒（MAPデータ値）
調査メモ（技術的な内容）
RMD MapActorSingle offset 0x0C = m_iRegenerationCycle（秒）。参考サーバ cNPC::isRegenerationTime は m_iLastTime + m_iRegenerationCycle <= 現在秒 で判定。マップエディタは 時/分/秒 に分解して表示。
